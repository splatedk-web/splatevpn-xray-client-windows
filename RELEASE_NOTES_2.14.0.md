В этом обновлении переработаны настройки, добавлены регионы маршрутизации, временные правила сайтов и новые инструменты для подключения и восстановления данных.

### Интерфейс
- Настройки разделены на категории с поиском. Поиск можно открыть сочетанием Ctrl+F.
- На главной появился компактный выбор между умным маршрутом и направлением всего трафика через VPN.
- Добавлена пошаговая настройка подключения.
- Убрана постоянная панель сохранения. Ошибки сохранения по-прежнему показываются явно.
- Превью тем кешируются, а анимации скрытых вкладок приостанавливаются. Уточнены тексты, подсказки и состояния элементов управления.

### Подключение и маршруты
- Добавлен SmartDNS через выбранный VPN-сервер и автоматическое переключение прямого SmartDNS при повторно подтверждённом отказе провайдера.
- Доступны регионы Россия, Китай, Иран и международный профиль. Региональные DNS и правила применяются только для выбранного региона.
- Можно сохранить до восьми сетевых профилей, посмотреть изменения перед применением и отменить последнее применение. Профили можно привязать к Wi-Fi или сетевому интерфейсу.
- Постоянные и временные правила сайтов объединены в одну форму. Добавлены просмотр совпадающего правила и автоматическое завершение временных исключений.
- Добавлена проверка выбранного DNS с отображением ответа, задержки и ошибок.
- Для новых настроек по умолчанию используется Real ping. Массовая проверка ограничена шестью слотами; при активном VPN часть слотов остаётся доступна балансировщику.
- Старые ошибки задержки после перезапуска больше не отображаются как свежие результаты.
- Добавлены внешний HTTP-прокси, импорт его настроек из Windows и проверка CONNECT. Исправлены переходы между системным прокси и TUN.
- Усилены проверки перед запуском: ошибки компонентов и занятых портов показываются до изменения сетевых настроек.
- Неподдерживаемые цепочки в JSON-профилях отклоняются при импорте, вместо потери промежуточных соединений.

### Подписки и резервные копии
- Добавлена история обновлений подписок с результатом, ошибкой и изменением числа узлов.
- Загрузку подписки можно отменить. Добавлены ограничение размера и общий таймаут; отменённая загрузка не заменяет текущий каталог.
- Папку личных конфигураций можно отключить целиком, включая серверы, добавленные позднее.
- При восстановлении копии доступны объединение и замена. Объединение сохраняет текущие настройки и существующие записи.
- Поддерживаются старые JSON-копии. Усилена проверка файлов перед восстановлением.
- Добавлены восстановление повреждённых настроек из рабочей копии и предпросмотр диагностического отчёта со скрытием секретов и адресов.

### Раздача и геобазы
- Для раздачи можно выбрать конкретный сетевой адрес. При его исчезновении приложение не переносит раздачу на другой интерфейс.
- Добавлена отдельная авторизация HTTP/SOCKS5 для устройств локальной сети, просмотр и генерация пароля, копирование адреса подключения.
- Обновлены инструкции подключения устройств по локальной сети.
- Геобазы проверяются по SHA-256 и ядром Xray перед установкой. Добавлен откат предыдущей пары баз.
- Подписки и геобазы при подключённом VPN загружаются через него.

### Установка
- **SplateVPN_Setup_v2.14.0.exe** — установщик для Windows x64.
- **SplateVPN_Portable_v2.14.0.zip** — версия без установки.
- **SplateVPN_v2.14.0_SHA256.txt** — контрольные суммы файлов.

WebView2 включён в оба пакета. Выбор отдельных Windows-программ пока не поддерживается: для охвата всех приложений используется TUN с правами администратора. Раздача работает через HTTP/SOCKS5 с приложениями, поддерживающими прокси.
