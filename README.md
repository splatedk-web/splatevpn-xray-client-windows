## ⚡ Ключевые возможности

### 🚀 Передовые протоколы и транспорты
* **VLESS** с поддержкой **XTLS Reality** и **Vision flow** — трафик маскируется под легитимные TLS-соединения с популярными веб-сервисами, делая его неотличимым для DPI.
* **XHTTP (SplitHTTP)** — передовой протокол доставки пакетов, устойчивый к блокировкам.
* **Trojan, VMess, Shadowsocks (2022 / AEAD)** — полная обратная совместимость с классическими протоколами.
* **Поддержка маскировки SNI**: автоматическое указание `verifyPeerCertByName` для сертификатов, выданных на IP сервера (Let's Encrypt IP SAN / RFC 8738).

### 🇷🇺 Умная маршрутизация и пользовательские правила
* **Режим «Обход блокировок (РФ)»**:
  * Заблокированные сервисы (YouTube, Discord, Instagram, Twitter, OpenAI, Rutracker и др.) направляются через зашифрованный туннель.
  * Российские ресурсы (Госуслуги, банки, Yandex, VK, Mail.ru, домены `.ru`/`.su`/`.рф`) и российские IP идут **напрямую** на максимальной скорости вашего провайдера.
  * Вам **больше не нужно отключать VPN**, чтобы перевести деньги в банке или зайти на Госуслуги!
  * Базируется на встроенных офлайн-геобазах `geoip.dat` и `geosite.dat`.
* **Свои правила маршрутизации (Custom Rules)**:
  * Поля в настройках: *«Всегда через VPN»* и *«Всегда напрямую / Исключения»*. Поддерживаются домены, IP-адреса, CIDR-подсети и geoip/geosite теги.
* **Прямой NTP (UDP 123)** для корректной синхронизации времени Windows.

### 🛡️ Глубокая защита от цензуры и утечек
* **Встроенный Split-DNS (FakeDNS)**: 
  * Внешние домены резолвятся через зашифрованные DNS (на выбор: Cloudflare, Google, Quad9, AdGuard).
  * Российские домены запрашиваются через быстрый DoH Яндекса для получения корректных CDN-адресов.
* **Блокировка QUIC (UDP 443)** — браузеры мгновенно переключаются на надежный TCP HTTP/2 / HTTP/1.1. Это решает проблему зависаний видео на YouTube и стримов Discord при выборочной блокировке UDP провайдерами.

### 💻 Системная интеграция Windows
* **Системный прокси (WinINet)**: Автоматическое включение системного прокси (`127.0.0.1:10809`) в один клик без запроса прав администратора.
* **Безопасное отключение**: при закрытии приложения прокси автоматически деактивируется, гарантируя стабильную работу интернета.
* **Системный трей и всплывающие уведомления**: скрытие в трей при сворачивании, контекстное меню, а также нативные системные уведомления Windows о подключении и отключении.
* **Автозапуск Windows**: интеграция в реестр для автоматического старта вместе с ОС.

### 🔄 Управление серверами и пинг
* **Удобный импорт**: быстрое добавление узлов из буфера обмена (`vless://`, `trojan://`, `vmess://`, `ss://`) или ссылки на подписку.
* **Двойной тест задержки**:
  * Быстрый **TCP Handshake** пинг до сервера.
  * Реальный **HTTP Proxy тест** сквозного прохождения пакетов через туннель (Cloudflare 204).

### 🐞 Интерактивный журнал отладки
* Встроенная консоль диагностики ядра Xray в реальном времени.

### 🎨 Премиальный дизайн (Obsidian & Cyber Cyan)
* Современный и стильный интерфейс на базе **WPF** и **WPF-UI**.
* **Cyber Power Core** — эффектная центральная кнопка подключения со световой индикацией статуса.
* **Telemetry HUD & Live Traffic Intensity** — отображение скорости скачивания и отдачи, индикаторы интенсивности трафика в реальном времени.
* Панель настроек с плавными анимациями.

## 📥 Установка и сборка

### Готовый установщик
1. Перейдите в раздел **Releases** репозитория.
2. Скачайте актуальный инсталлятор приложения (`SplateClient_Setup.exe`) или Single-File bundle `SplateClient.exe`.
3. Установите и запустите приложение.

> **Системные требования**: Windows 10 или 11 (архитектура x64).

### Сборка из исходного кода
Для сборки проекта на локальном компьютере:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/splatedk-web/splatevpn-xray-client-windows.git
   cd splatevpn-xray-client-windows
   ```

2. Откройте проект в **Visual Studio 2022** или **JetBrains Rider**.
3. Убедитесь, что папка `core` присутствует в корне приложения и содержит `xray.exe`, `geoip.dat` и `geosite.dat`.
4. Соберите проект:
   * Используя IDE (Build -> Build Solution)
   * Либо через терминал с помощью .NET CLI:
     ```bash
     dotnet build -c Release
     ```
5. Для сборки инсталлятора используйте PowerShell-скрипт `build_installer.ps1` (потребуется установленный Inno Setup Compiler `iscc`).
