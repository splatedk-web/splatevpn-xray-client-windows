# История изменений SplateVPN Desktop

Архив заметок до обновления README от 20 октября 2026 года. Описания относятся к указанным версиям; актуальные возможности, ограничения и инструкции находятся в [README.md](README.md).

# SplateVPN Desktop 2.12.4

Готовые сборки: `installer_output/SplateVPN_Setup_v2.12.4.exe` и `installer_output/SplateVPN_Portable_v2.12.4.zip`. Перед запуском новой версии закройте предыдущую: клиент допускает один экземпляр.

## Изменения 2.12.4

- В узлах результаты TCP/HTTPS появляются по мере проверки, без ожидания всего списка. Видны количество проверенных узлов и кнопка остановки; остановка сохраняет полученные результаты, не обнуляет непроверенные и не отключает VPN.
- Контрольные HTTPS-сайты проверяются параллельно в общем временном бюджете. Успешный HTTP 204 сразу подтверждает отклик, даже если другой контрольный сайт не отвечает. Открытый TCP-порт по-прежнему не подтверждает работоспособность VPN.
- Для проверенного узла без ответа отображается «Нет ответа»; непроверенные узлы сохраняют прежнее значение.
- Проверены потоковое обновление, отмена и повторный запуск, а также реальные TCP/HTTPS-проверки при активном TUN на компьютере разработчика.

## Изменения 2.12.3

- Исправлена проверка кандидатов балансировщика при активном TUN. Временное ядро привязывает все сетевые выходы к физическому адаптеру; его DNS идёт отдельным маршрутом через DoH. Проверка резервного сервера больше не зависит от работоспособности текущего VPN.
- TCP-пинг при TUN привязан к физическому интерфейсу; публичные имена разрешаются через отдельный DoH-запрос на том же интерфейсе. Массовый TCP-пинг использует один снимок маршрута. Изменение режима TUN/адаптера отменяет устаревшие результаты.
- Автовыбор и балансировщик повторно проверяют до трёх лучших кандидатов перед переключением. Открытый TCP-порт и успешный запуск Xray не считаются работающим VPN: требуется HTTP 204 через конфигурацию кандидата.
- Если начальный автоматический подбор не подтвердил ни одного узла, клиент показывает причину и больше не подключает молча прежний непроверенный узел. Ручное подключение остаётся доступным без обязательной внешней HTTP-проверки. При отсутствии резерва уже работающий TUN сохраняется.
- Увеличено время готовности временного ядра на медленных компьютерах, исправлена передача отмены. Показатель задержки диагностики больше не суммирует ожидания предыдущих неудачных проверок.

## Изменения 2.12.2

- Основной статус соединения снова «Подключено». Фоновая диагностика не переименовывает подключение; проблемы определения IP и связи отображаются в соответствующих данных и подробностях.
- Блок нейросетей расположен под выбранным сервером, используя свободное место слева. График теста скорости скрыт до появления результатов, поэтому карточка инструментов больше не резервирует пустую область.
- Упрощено меню узлов: фильтр источника всегда виден, управление подписками свёрнуто отдельно. Добавлены контекст текущего выбора, переход к выбранному узлу и сброс фильтров. Редкие операции импорта/экспорта и метод проверки находятся в меню «Ещё».
- У каждого узла есть явная кнопка выбора и актуальная метка «Выбран» / «Подключён». Редактирование, ссылка / QR и удаление собраны в меню «⋯». Открытие этого меню не переключает сервер.

## Изменения 2.12.1

- Исправлен выбор физического адаптера TUN: маршрут выбирается по индексу с учётом метрики интерфейса, имя берётся через .NET без преобразования кодировки PowerShell. При переключении и восстановлении сервера адаптер определяется заново. Ошибка привязки ядра вызывает ограниченную по частоте попытку восстановления и явное сообщение об ошибке маршрута.
- Нейросети переключаются на главной одним списком: обычные правила, VPN или SmartDNS. Режим и провайдер применяются автоматически к активному соединению. Убраны устаревший Xbox DNS и пересекающиеся переключатели; старые настройки мигрируют на выбранный SmartDNS, общий Xbox DNS заменяется Cloudflare.
- Проверка SmartDNS сначала выполняет настоящий DoH-запрос по HTTP/2 с проверкой DNS-пакета и адресов, затем проверяет страницы Gemini, ChatGPT и Claude. Показаны отдельные ошибки DNS, TLS, HTTP и региональные запреты.
- Подбор для Gemini повторно подтверждает доступность того же сервиса. Кандидат дополнительно загружается с JavaScript в изолированном WebView2 через собственный SOCKS-маршрут. Текст «Gemini isn’t currently supported in your country» считается региональным запретом даже при HTTP 200; CAPTCHA и «Something went wrong» не считаются подтверждённым доступом. Вход в аккаунт и автоматическое прохождение CAPTCHA не выполняются; работа аккаунта не гарантируется.
- Общая диагностика проверяет три нейросети, включая загруженную страницу Gemini. Запросы внешнего IP идут через выбранный VPN раньше правил Smart RU / прямых пользовательских маршрутов. Вместо выдуманного «Скрыт (VPN)» выводится отсутствие результата. При неудаче проверки связи VPN остаётся включённым; статус не утверждает, что защита подтверждена.

## Изменения 2.12.0

- Переработаны шесть тем: оригинальные иллюстрации сакуры, неоновых зданий, океана, заката, сияния и красных скульптур. Части атласов имеют собственные опорные точки, маски, покачивание, параллакс и пульсацию. Фоны включают дымку, свет, дождь, луну, пузырьки и частицы; превью неподвижны. Палитры сверены с текущими исходниками эталона. Стекло и переключатель блюра сохранены.
- В «Маршрутах» доступны семь провайдеров SmartDNS: DNS-AI, GeoHide RU/EU, MALW, MALW · CF, Zapret DNS и Comss.one. Общий DNS и SmartDNS нейросетей независимы. TLS-фрагментация SmartDNS вынесена в отдельный переключатель и по умолчанию выключена. DNS-запросы провайдера не фрагментируются.
- Автоподбор проверяет 14 комбинаций по публичным страницам ChatGPT, Gemini и Claude через отдельный процесс Xray. Региональные запреты, CAPTCHA, ограничения HTTP и редиректы не считаются полным успехом. До трёх лидеров проверяются повторно. При равенстве результатов предпочтение получает вариант без фрагментации. Подбор не останавливает VPN; отмена, ручная смена AI-параметров, смена сети и отсутствие подтверждённого результата сохраняют прежний выбор. После подтверждения настройки сохраняются и применяются переподключением активного соединения.
- Уточнён явный список AI-адресов прямого SmartDNS-маршрута. Остальные поддомены не отправляются в обход VPN автоматически. Обычные Cloudflare/Google/Quad9/AdGuard DNS используют обычный DNS-транспорт ядра, собственный DoH — HTTPS. Известные SmartDNS-адреса без пути получают `/dns-query`.
- Встроена обновляемая доменная база AdGuard DNS с дополнительными правилами РФ и исключениями до 100 доменов. Она компилируется в компактный GeoSite с проверкой SHA-256; исключения включают поддомены. База и правила DNS применяются до прямых маршрутов, включая FakeDNS. Для новых установок блокировка включена по умолчанию; прежний сохранённый выбор сохраняется.
- Пока клиент запущен и блокировщик включён, база проверяется на ежедневное обновление. Фоновая загрузка не переподключает VPN; ручная кнопка «Обновить фильтры» применяет успешную загрузку переподключением. При сетевой ошибке остаётся прежняя база. Источник, GPL-3.0 и уведомления входят в `Assets/licenses`.
- Провайдер, TLS-фрагментация и исключения входят в резервную копию. Исправлена прокрутка при переходе между разделами.

Автоподбор оценивает публичные страницы без авторизации. Результат зависит от сети и провайдера; он не гарантирует работу входа в аккаунт и всех функций AI-сервисов. Блокировщик фильтрует домены проходящего через клиент трафика и не удаляет рекламу внутри ответов общих API.

Тестовые домены направляются через VPN перед правилами прямого доступа. Тайм-аут отличается от ручной остановки. Проверка не отключает VPN.

- В настройках доступны установленная версия, результат проверки, повторная проверка и переход к скачиванию релиза. Сетевые ошибки отображаются явно; повторная неудачная проверка не скрывает уже найденное обновление.

## Изменения 2.11.4

- Интерфейс запускается с включённым Microsoft WebView2 Fixed Version Runtime 155.0.4283.45. Системная установка WebView2, Bootstrapper и браузер не нужны; Setup копирует приложение со всеми файлами, portable запускается после полной распаковки.
- Для Windows 10 автоматически готовится рекомендованный Microsoft доступ AppContainer к папке собственного Runtime. Глобальные политики и системный установщик Edge не меняются.
- Причина ошибки 0x80040902 в проверенной Sandbox: внутренний код установщика 11, отказ в доступе при создании временного каталога, при 74 ГБ свободного места. Реестр Runtime там также не соответствовал файловому состоянию. Новый путь не использует этот установщик или его регистрацию.
- Fixed Runtime обновляется вместе со сборками SplateVPN. Папка runtime должна оставаться рядом с приложением.

В portable кнопка установки запускает тот же полный пакет без браузера; показываются индикатор и время ожидания. Пакет стал больше примерно на 204 МБ.

- Установщик проверяет наличие WebView2 Runtime и предлагает установить его официальным Microsoft Bootstrapper. В portable включён тот же установщик; при отсутствии Runtime показывается нативный экран установки и повторного запуска. Нужен интернет, для автономной установки используйте Evergreen Standalone Installer x64.


- В теме Winx под выбранным сервером появился Кико, питомец Блум: прозрачная иллюстрация с мягкой анимацией. При сокращении движения анимация отключается.

## Изменения 2.11.0

- Исправлено ложное отключение VPN из-за внешнего HTTP-тайм-аута. Запуск проверяет локальную готовность SOCKS. Неудачная диагностика не выключает соединение.
- Смена сервера сохраняет TUN и время/трафик сеанса. Конфигурация проверяется до остановки старого Xray; при ошибке запуска восстанавливается предыдущий сервер. Замена ядра может оборвать существующие TCP-соединения: приложениям потребуется переподключить их.
- Балансировщик: сбалансированный режим, только резервирование, только первоначальный выбор. Настраиваются частота проверки, число неудач, период оптимизации, пауза и требуемый выигрыш. Высокий успешный пинг не считается отказом; неудача подтверждается отдельным запросом. Без проверенного резерва VPN остаётся включённым. Оптимизация приостанавливается во время спидтеста и активной загрузки.
- Все 12 тем используют актуальные палитры, оригинальные изображения Pony/Winx и отдельные анимированные фоны. Первые четыре плитки и раскрытие полного списка; стекло меняется сразу, сохраняется и сбрасывается. Исправлен контраст светлых тем и оформление мини-виджета.
- Убраны платформенные заметки из интерфейса. Группировка серверов включена по умолчанию; отключённые папки видны, их узлы исключены из выбора. Перетаскиваемая капсула переключает разделы и категории. Метод пинга TCP/HTTPS выбирается явно.
- Спидтест: два потока, отдельный прогрев, проверка ответа, график, Мбит/с и МБ/с, байты и время. Отмена и смена сервера закрывают загрузки; недоступный HTTPS-пинг не отображается как ноль.
- Сохранены три встроенные подписки, управление источниками, импорт/экспорт, правила маршрутизации, фрагментация, Mux, DNS-AI и VPN для нейросетей.

Актуальные возможности и ограничения описаны в [README.md](README.md).

## Запуск

Распакуйте portable ZIP целиком и запустите `SplateClient.exe`. Папки `core`, `wwwroot` и native-компоненты WebView2 должны оставаться рядом с приложением. Microsoft Edge WebView2 Runtime уже включён в папку runtime.

Для программ без поддержки системного прокси: в настройках нажмите «Запустить от администратора», включите TUN и подключитесь. При отказе TUN приложение показывает ошибку и освобождает ресурсы. Обычный режим прокси доступен без прав администратора, но охватывает только приложения с поддержкой прокси.

Настройки и серверы хранятся в `%APPDATA%\SplateVPN`. После отключения восстанавливается прежний системный прокси. После аварии прежний прокси восстанавливается при следующем запуске клиента. Собственные Xray и tun2socks связаны с Windows Job Object, поэтому не остаются работающими после завершения владельца.

## Возможности

- VLESS, Reality, TLS, XHTTP, WebSocket, Trojan, VMess, Shadowsocks.
- TUN для IPv4/IPv6; блокировка перехваченного IPv6 и QUIC настройками ядра.
- Smart RU, глобальный режим и пользовательские правила доменов/IP/CIDR.
- DNS-AI, VPN для нейросетей и отдельный Xbox DNS; выбор маршрута в настройках.
- 12 тем, оригинальные иллюстрации Pony/Winx, анимированные фоны и регулировка стекла.
- Подписки, редактирование серверов, QR из файла, импорт/экспорт, трей, автозапуск.
- Скорость и объём VPN-трафика из метрик Xray, а не общих счётчиков адаптеров.

Kill Switch и отдельная защита глобальной DNS-политикой недоступны: прежняя реализация не обеспечивала заявленное поведение. Windows-маршрутизация по процессам через Xray не поддерживается; вместо неё доступны правила доменов и IP. В режиме прокси настройки IPv6/QUIC применяются только к трафику ядра.

## Сборка и проверки

```powershell
dotnet build -c Release
dotnet run --project tests/PortChecks/PortChecks.csproj -c Release
node tests/ui-check.cjs
./build_installer.ps1
```

PortChecks проверяет десять конфигураций реальным Xray, локальную передачу данных через прокси, метрики, конфликты портов и завершение дочернего ядра при аварии владельца. UI-тест использует Playwright и установленный Edge. В тестовом файле путь к Playwright можно заменить на локальный пакет.

Сборка установщика требует Inno Setup 6; без него создаётся portable ZIP. Упаковка проверяет наличие ядра и файлов интерфейса. Удаление приложения сохраняет пользовательские профили.

Полноценное подключение TUN к реальному VPN-серверу и работа Codex требуют отдельной проверки на используемой сети. Автоматические проверки не меняют системный прокси и маршруты Windows.

## Совместимость старых профилей

При первом запуске 2.9.1 несовместимые параметры автоматически приводятся к рабочему режиму. Исходный файл сохраняется как settings.before-2.9.1.json рядом с settings.json. Старые списки приложений сохраняются, но не применяются на Windows. FakeDNS отключается без TUN или sniffing. Обновление подписок при активном подключении использует локальный VPN-прокси. Таймауты подключения показываются отдельно от ошибок формата подписки.


В 2.9.2 исправлен выбор серверов: отметка в списке обновляется при получении состояния, выбор во время подключения отменяет предыдущую попытку и запускает выбранный узел. При нескольких быстрых выборах применяется последний запрос. Карточка сервера на главной открывает список. Исправлена передача порта метрик ядру.

В 2.9.3 автосохранение подтверждается внутри настроек. Уведомления импорта, ошибок и подключения показываются в приложении; подтверждения удаления и обновления подписки используют встроенный диалог. Вставка URL подписки больше не открывает отдельное окно. В настройках добавлены параметры для Codex: TUN, sniffing, маршруты ИИ через VPN, Cloudflare DNS. Изменения сети применяются после переподключения с правами администратора. Диагностика проверяет выходной IP и HTTP-ответ сайта ChatGPT через активный SOCKS-прокси, без токенов аккаунта; она не подтверждает доступ к авторизованным запросам Codex.

В 2.9.4 исправлен запуск tun2socks: используется драйвер tun://SplateTUN. Перед установкой маршрутов приложение ожидает готовности IPv4/IPv6 адресов Windows. Отдельная проверка `dotnet run --project tests/PortChecks/PortChecks.csproj -c Release -- --tun-only` требует прав администратора, создаёт временный адаптер и проверяет IPv4/IPv6 HTTP через tun2socks, локальный SOCKS и локальный HTTP-сервер. Она устанавливает только маршруты к тестовым адресам 192.0.2.2/32 и 2001:db8:5350::2/128, не меняет основной маршрут или системный прокси.

В 2.9.5 добавлен отдельный переключатель «Разблокировщик нейросетей — Xbox DNS» в разделе маршрутизации. Домены OpenAI и Gemini разрешаются через https://xbox-dns.ru/dns-query, остальные домены используют выбранный DNS. Для этих доменов используется отдельный outbound выбранного VPN с принудительным локальным разрешением, поэтому результат Smart DNS передаётся VPN-серверу как IP. Включается sniffing с заменой адреса назначения, чтобы режим работал и при соединениях к уже закешированным IP в TUN. При ошибке выделенного DNS ответ основного DNS для ИИ не подставляется. Трафик включён в общий счётчик. Настройка по умолчанию выключена, применяется при переподключении. Проверка `--ai-dns-only` использует локальные DNS/SOCKS-заглушки и настоящий Xray, не меняя сеть пользователя.

В 2.9.6 режим Xbox DNS использует самостоятельный прямой маршрут: запросы DoH идут через dns-xbox → direct, а OpenAI/Gemini через ai-smartdns (freedom, ForceIPv4). Оба маршрута привязаны к физическому интерфейсу при работе TUN и не используют выбранный VPN-сервер. Правило Smart DNS для этих доменов имеет приоритет над обычными правилами VPN. При ошибке DNS нет подстановки системного DNS или VPN-маршрута. Проверка --ai-dns-only подтверждает передачу данных и запросов DNS без подключения к заглушке VPN-сервера. Проверка --xbox-probe выполняет неавторизованные GET к ChatGPT и Gemini через настоящий Xbox DNS, без изменения системной сети; она не подтверждает доступ к аккаунту или Codex.


## 2.9.7 — интерфейс и проверка основных сценариев

- Обновлены главная страница и настройки: читаемые подписи, статус активного маршрута ИИ, быстрые переключатели рядом со статистикой. Сетевые настройки явно требуют переподключения.
- Серверы: поиск по подписке, сортировка по имени и задержке, корректные личные/подписные фильтры и пустые состояния. Выбор с клавиатуры, доступные переключатели и встроенное окно добавления с Escape/Ctrl+Enter.
- Журнал: поиск, фильтр ошибок, отключаемое следование за новыми событиями, выделение текста. График обновляется при поступлении данных/изменении размера вместо непрерывного цикла 60 FPS.
- Автовыбор сохраняет ручной выбор при завершении устаревшей проверки, работает на UI-потоке и не выбирает произвольный сервер при неудаче. Удаление выбранного узла отключает соединение; удалённые узлы не могут подключиться из очереди.
- Кнопка обновления обрабатывает все подписки; обновление одной подписки не выбирает одноимённый сервер из другой. Фоновое обновление использует тот же путь замены выбранного узла.
- Списки серверов/подписок записываются атомарно; ошибка записи больше не скрывается. Повреждённые резервные копии отклоняются до изменения сохранённых данных; ошибки импорта/экспорта показываются внутри приложения.
- После редактирования устаревшая исходная ссылка больше не перезаписывает поля при следующем запуске. Обновление коллекции после импорта корректно передаётся WebView.
- Проверки: сборка без предупреждений; браузерные сценарии на 820–1440 px и во всех темах; Xray-конфигурации, локальная передача/метрики/изоляция процессов, Smart DNS и сохранность данных при ошибке импорта/записи. Проверки браузера используют тестовый IPC; это не полная автоматизация нативных окон Windows.
