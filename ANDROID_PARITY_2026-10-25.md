# Сверка с Android и изменения Windows 2.14.0

Эталон: журнал изменений, предоставленный пользователем 25 октября 2026 года. Это продолжение существующего переноса 2.13.1; ранее сделанные изменения сохранены. Полный паритет со всеми пунктами Android пока не достигнут.

## Добавлено в этом изменении

- Настройки с поиском, категориями, иконками и переходом к поиску по Ctrl+F. Профили и внешний прокси находятся в настройках. Постоянная панель сохранения убрана; ошибки сохранения остаются видимыми.
- Компактный выбор умного/полного маршрута на главной. Регион настраивается отдельно: Россия, Китай, Иран, международный профиль. Региональные DNS и правила не добавляются для других регионов. Международный профиль оставляет пользовательские правила, без региональных исключений.
- Пошаговая настройка региона, маршрута, добавления сервера и режима охвата приложений. Доступна из настроек; автоматически предлагается при пустом каталоге. Языкового шага пока нет.
- Постоянные и временные правила сайтов в одной форме. Временные правила на 15 минут, час, 8 или 24 часа, удаление и истечение срока с переприменением конфигурации. Просмотр совпадающего доменного правила использует генератор конфигурации; зависимость от геобазы/IP и блокировщика обозначена явно.
- Проверка DNS: выбранный провайдер, ответ A, задержка и ошибки. DoH выбранного провайдера, для Yandex — TCP к его DNS. При активном VPN проверка использует локальный HTTP-прокси. Это проверка провайдера, а не тест отсутствия DNS-утечек всей системы.
- Сетевые профили можно привязать к текущему SSID Wi-Fi либо мобильному/другому физическому интерфейсу. При устойчивой смене сети привязанный профиль применяется с возможностью отката. Для SSID используется Windows WLAN API; без разрешений Windows привязка сообщает об ошибке. Для мобильного/проводного подключения привязка относится к интерфейсу, не к конкретному оператору/проводной сети.
- История последних 100 обновлений подписок: время, результат, ошибка и число узлов до/после. Отмена прерывает загрузку, не запускает резервный запрос и не заменяет каталог. Чтение ограничено 32 МБ, действует общий таймаут, разбор выполняется вне UI-потока.
- Папку личных конфигураций можно отключить целиком, включая добавленные позднее узлы. Отключённые узлы не участвуют в выборе/балансировке.
- Real ping по умолчанию только для новых настроек. Массовая проверка: до шести кандидатов, при активном VPN — до четырёх в пользовательском задании; общий лимит HTTPS-проверок кандидатов — шесть. Ожидание семафора не входит в таймаут измерения. Старые отрицательные результаты сбрасываются при загрузке.
- Восстановление копии: объединить или заменить. Объединение сохраняет текущие настройки и записи с существующими ID, добавляет новые серверы/подписки. Поддержаны незашифрованные JSON-копии при сохранении старого зашифрованного формата и AES-256-GCM. Ограничение 32 МБ и проверка структуры до записи; запись набора файлов остаётся транзакционной.
- Геобазы: SHA-256 из файлов контрольных сумм источника и проверка совместимости реальным Xray перед заменой. Предыдущая пара сохраняется для проверяемого отката. Обновление при активном VPN использует его HTTP-прокси. Откат/обновление применяются ядром при следующем подключении.
- Раздача: выбор конкретного IPv4-интерфейса, отдельная авторизация HTTP/SOCKS5 для LAN, просмотр/генерация пароля, копирование HTTP-адреса. Локальные клиенты и TUN используют отдельные loopback-входы без пароля. Выбранный адрес не заменяется другим при исчезновении интерфейса. Старый вариант «все интерфейсы без авторизации» сохранён явно.
- Статичные превью тем кэшируются. Анимации скрытых вкладок приостановлены; сохраняются темы, размытие, сокращение движения и общие цветовые токены. Добавлены состояния фокуса и проверены ширины 820–1440 px.
- Из интерфейса, README и профильных тестовых примеров убраны личные сведения о сети пользователя. Примеры используют зарезервированный `example.com`. Уточнены русские названия маршрута, прокси и времени отклика.
- JSON-профили с неподдерживаемыми цепочками не превращаются молча в отдельные узлы; самостоятельные поддерживаемые outbound-профили импортируются с последующим применением настроек клиента.

## Уже существовало и сохранено

SmartDNS через VPN, прямой SmartDNS с подтверждённым переключением провайдера, JavaScript-проверка Gemini, до восьми профилей с предпросмотром и откатом, XHTTP/REALITY pqv, QR из файла, шифрованные копии, восстановление повреждённых настроек, метаданные подписок, отдельные проверки кандидатов Xray, отмена пинга, очищенная диагностика, инструкции LAN, сохранение TUN и статистики при смене сервера. Старые проверки этих возможностей продолжают проходить.

## Осталось для полного соответствия списку Android

1. Выбор отдельных Windows-программ: «все / выбранные / все кроме выбранных», отложенное применение, поиск и правила под каждым приложением. Текущие Xray + tun2socks не определяют Windows-процесс для маршрутизации. Нужен отдельный механизм перехвата/маршрутизации процессов; старые списки хранятся, но не применяются. В мастере доступны системный прокси и TUN с явным описанием охвата.
2. Полная локализация интерфейса и нативных диалогов на упрощённый китайский и персидский, выбор языка независимо от региона и RTL. Сейчас исправлен русский текст, регион независим от языка, но языкового переключателя нет.
3. Точное воспроизведение новых Android-анимаций воды/медуз, гор северного сияния и прочих объектов требует отдельной визуальной сверки с актуальными Android-сценами. Этот прогон проверяет существующие темы, кэш и остановку анимаций, а не заявляет покадровое соответствие новым сценам.
4. Автоматическая загрузка/установка обновлений клиента и её отмена: Windows по-прежнему открывает страницу релиза для загрузки, поэтому Android-исправления этого механизма не считаются перенесёнными.
5. Требования Android, связанные с Google Play services и переключением мобильного системного VPN, неприменимы напрямую к Windows. В реальном окружении отдельно нужны проверки WLAN-привязки, смены физических сетей, LAN-клиентов с авторизацией и учётных записей AI.

## Проверки

- `dotnet build -c Release --no-restore`: без ошибок и предупреждений.
- Полный `dotnet run --project tests/PortChecks -c Release`: успешно. Включает настоящие локальные Xray/VLESS/HTTP-стенды, конфигурации, импорт, маршруты, балансировщик, отмену и восстановление.
- `--desktop-refresh-only`: четыре региона проверяются настоящим `xray run -test`, включая конфигурацию LAN с авторизацией; IDN, истечение временных правил, предпросмотр, DNS-пакеты, объединение/замена копий, JSON-цепочки и отмена чтения подписки.
- `--audit-fixes-only`: хранение, шифрование, повреждение копий, откат записи, обновление геобаз и восстановление предыдущей пары.
- UI: `ui-check.cjs`, `android-ui-check.cjs`, `route-ui-check.cjs`, `update-ui-check.cjs`, `theme-ui-check.cjs`, `desktop-refresh-ui-check.cjs`, `blur-animation-check.cjs`.
- Браузерные сценарии используют тестовый IPC; это не доказательство работы внешних VPN/AI-аккаунтов. Снимки новых экранов: `tests/artifacts/desktop-refresh/`.
